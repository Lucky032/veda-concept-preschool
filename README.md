# Veda Concept Preschool — Static Landing Page

A responsive, premium-style React + Vite landing page demo for Veda Concept Preschool.

## Run locally

1. Install Node.js (LTS recommended).
2. Open this folder in VS Code or a terminal.
3. Run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

The production-ready static files are generated in `dist/` and can be deployed to Vercel, Netlify, or another static host.

## Included

- Responsive single-page design with mobile navigation
- Hero, welcome/about, programs, why choose us, activities, gallery, admissions CTA, contact form and footer
- Recreated book/rainbow logo as `public/veda-logo.svg`, inspired by the supplied school signboard
- School phone numbers and email from the supplied signboard
- WhatsApp enquiry flow (no backend/database)
- Reveal-on-scroll effects and reduced-motion support

## Before sharing with the school

- Images are sample images loaded from Unsplash and require an internet connection. Replace them with approved school photos for a final website.
- Confirm school address, timings, fee details, admissions status and curriculum wording before publishing.
- The enquiry form opens WhatsApp and does not save submissions on a server.
- The recreated logo is a demo interpretation, not the original high-resolution logo artwork.
